# SAKANY | سكني

واجهة تجريبية عربية RTL للبحث عن سكن داخل مدينة طيبة – الأقصر فقط.

## التشغيل
1. فك ضغط `sakany-project.zip`.
2. افتح `index.html` في متصفح حديث مثل Chrome أو Edge أو Safari.
3. لا يحتاج المشروع إلى تثبيت أو خادم في هذه المرحلة.

## المميزات
- تصميم Responsive للكمبيوتر والتابلت والهواتف.
- بحث حسب المنطقة ونوع السكن والحد الأدنى للسعر (700 جنيه شهريًا).
- بطاقات عقارات وتفاصيل الإعلان والاتصال الهاتفي.
- إضافة إعلان تجريبي مع صورة من الهاتف أو الكمبيوتر.
- تغيير صورة الواجهة وصورة أي عقار من أزرار الكاميرا.
- حفظ الإعلانات والصور محليًا في المتصفح باستخدام LocalStorage.
- كل بيانات العرض التجريبية محصورة في مدينة طيبة، وتشمل منطقة المساكن.

## تغيير الصور
- صورة الواجهة: زر «تغيير صورة الواجهة» أعلى صورة البداية.
- صورة عقار: مرر على البطاقة (أو اضغط زر الكاميرا على الهاتف) ثم «كاميرا +».
- إعلان جديد: اختر صورة من حقل «صورة السكن» عند إضافة الإعلان.

## ملاحظات مهمة
- هذا Frontend تجريبي؛ لا يوجد Backend أو حسابات أو حجز فعلي أو تحقق من هوية الملاك.
- الإعلانات والصور تحفظ على نفس المتصفح والجهاز فقط. لمسح بيانات التجربة يمكن مسح بيانات الموقع من إعدادات المتصفح.
- صور العقارات الافتراضية تحتاج اتصالًا بالإنترنت، بينما الصور التي يرفعها المستخدم تحفظ محليًا.
- لا تضع بيانات شخصية حساسة في النسخة التجريبية.
